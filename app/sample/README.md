# サンプルZIP置き場

初回起動時に同梱する「お手本フォルダ」用のZIPファイル10個をここに置く（REQUIREMENTS.md 6.7）。Geminiから保存したZIPをそのままのファイル名で入れればよい。

## ここに入れるもの

「ホテル滞在を快適にする一言」フォルダ用の10フレーズ（英語:イギリス英語／声:標準(Kore)で統一）:

1. チェックイン予定より早く着いてしまったので、荷物だけ先に預かってもらえますか？
2. 部屋に入ったらタバコの匂いが残っていたので、部屋を変えてもらえますか？
3. 両替はできますか？
4. エアコンの効きが悪いので、部屋を変えてもらえますか？
5. 明日の朝、タクシーを呼んでもらえますか？
6. 隣の部屋の音がうるさくて眠れません、静かにしてもらえますか？
7. 毛布をもう一枚もらえますか？
8. もう1泊できますか？
9. チェックアウト後も2時間だけ荷物を預かってもらえますか？
10. 明日の朝食の時間を7時に変更できますか？

※旧「海外旅行」10フレーズのZIPはこのフォルダから削除して、上記10個に差し替える。
